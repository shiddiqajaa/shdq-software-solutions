# SHDQ IT Solutions - Agency Landing Page

A high-performance corporate landing page built to showcase technical hardware and software solutions capabilities. This project features modern UI animations and optimized frontend performance.

## 🚀 Tech Stack
* **Frontend:** React, Vite, Tailwind CSS
* **Tooling:** Git, Node.js

## 🛠️ Installation & Setup
To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com https://github.com/shiddiqajaa/shdq-software-solutions
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
